# Research Council

**AIによる独立した回答、相互レビュー、人が承認した実験の実行を、ひとつのローカル研究ワークスペースに。**

[English](README.md) · [中文介绍](README.zh-CN.md) · [アーキテクチャ](docs/ARCHITECTURE.md) · [開発ノート](docs/DEVELOPMENT.md) · [macOSビルドガイド](desktop/README.md)

![独立した回答と研究記録をまとめて確認できるResearch Councilの画面](docs/images/research-workspace.png)

スクリーンショットにはデモ用の文章と独立したテストデータを使用しています。個人の研究記録は含まれておらず、実際のモデル性能を示すものではありません。

## 開発の背景

複数のAIアシスタントを研究に使うと、回答、異論、実行計画、実験結果が別々のチャットに分散しがちです。どの主張が検討され、どの計画が承認され、結果が独立に検証されたのかを追うことも難しくなります。

Research Councilでは、まず各モデルが独立に回答し、その後、公開された回答を参照しながら順番に相互レビューします。実験は会話から分離したタスクとして扱い、人が計画と受け入れ基準を確認してから、実行担当と独立した検証担当に引き継ぎます。

モデル同士の合意と、証拠に基づく検証の完了を区別して記録します。

## 主な機能

- **独立回答と順次相互レビュー**：他のモデルの回答を共有する前の判断と、共有後のレビューを区別します。
- **実験タスク専用の操作**：計画、未解決の異論、受け入れ基準を確認してから実行します。通常の質問では実験を開始しません。
- **永続的な段階記録**：実行、チェックポイントでのレビュー、実行の継続、最終検証の履歴を保存します。失敗時の状態や未決事項も残します。
- **分かりやすい判断待ち表示**：ユーザーの判断が必要な場合は待機状態として表示し、実際の呼び出しエラーとは区別します。
- **研究資料とノート**：ローカル資料、引用カード、画像、個別の補足チャット、選別した研究ノートをまとめて扱えます。
- **確認できる進捗**：ツールの動作、経過時間、権限確認、クライアントが提供する利用枠やコンテキスト情報を表示します。
- **デスクトップとブラウザー**：SwiftによるmacOSネイティブウィンドウ、日本語・英語・中国語、ライト・ダーク・システム連動の外観に対応します。

![実験タスクと実行・検証の段階記録](docs/images/experiment-tasks.png)

この画面の完了状態はテストシナリオによるもので、科学的な実験結果ではありません。

## 技術構成

フロントエンドはJavaScript、HTML、CSSで構成しています。Pythonサービスが議論の進行、CLIセッション、タスク記録、ローカル保存を担当し、macOSアプリの外枠にはSwift、AppKit、WKWebViewを使用しています。

ClaudeとCodexは、インストール・ログイン済みのCLIを利用します。Geminiは任意のAntigravity CLIによる研究用連携です。Grokは現在デモ設定のみで、実際の呼び出しには接続していません。画面上のモデル選択肢は、アカウントでの利用権限を保証するものではありません。

作業ディレクトリ自体はOSのサンドボックスではなく、実際のファイルアクセス範囲はCLIの権限設定に従います。また、ローカル保存とオフライン推論は異なります。Live CLIでは、入力内容や選択した資料が対応するモデルサービスへ送信されます。

## ローカルで実行する

**Python 3.11以上**が必要です。ブラウザー向けフロントエンドには、本番用のnpm依存パッケージはありません。

```sh
git clone https://github.com/nicoyoung1101/research-council.git
cd research-council
python3 bridge.py
```

**http://127.0.0.1:8765/index.html** を開きます。まずはDemoモードで操作を確認できます。実際のモデルを呼び出すには、対応するCLIを別途インストールしてログインし、**Agents & Models**で明示的に**Live CLI**へ切り替えてください。認証情報はリポジトリに含まれていません。

### macOSアプリをビルドする

macOS上でXcodeコマンドラインツールとPython 3.11以上を用意し、次を実行します。

```sh
python3 desktop/build_app.py --output 'dist/Research Council.app'
open 'dist/Research Council.app'
```

公開ソースは**v0.11 / Build 48**を基にしています。ビルドしたアプリはローカルのPythonを使用し、アドホック署名を付与します。Appleの公証を受けた、単体で動作する配布パッケージは現在提供していません。保存先や更新方法は[macOSビルドガイド](desktop/README.md)をご覧ください。

## 検証と公開範囲

Build 48は、ローカルで**320件のPythonテストと33組のブラウザーシナリオテスト**を通過しています。ブラウザーテストにはテスト用の実行処理を注入し、実際のモデルは呼び出しません。

```sh
python3 -m unittest discover -s tests -v
node tests/research-workflow.cjs
node tests/conversation-scroll.cjs
```

ブラウザーテストにはNode.js、Playwright、Chromeが必要です。元の開発用Mac以外では、Playwrightを含むディレクトリを`RC_NODE_MODULES`に指定してください。一部のシナリオはmacOS標準のChromeインストール先を使用しています。詳しくは[英語版README](README.md#validation)をご覧ください。

公開リポジトリにはソース、テスト、文書を含めています。個人の会話、ジョブ記録、認証情報、非公開の作業ディレクトリ、インストール済みのアプリは含めていません。フィードバックは初期設定ではローカルにのみ保存します。

第三者コンポーネントのライセンスと帰属表示は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)に記載しています。アプリ独自のコードには、プロジェクト全体のライセンスをまだ指定していません。
